# معرفت

برنامهٔ Flutter برای مطالعهٔ EPUB، با رابط فارسی/دری و فهرست کتاب‌های خواندنی. کاربر می‌تواند کتاب‌ها را جست‌وجو، نشانه‌گذاری و مطالعه کند؛ بارگذاری کتاب تازه توسط کاربر ممکن نیست.

## راه‌اندازی

1. وابستگی‌ها: `flutter pub get`
2. اجرا: `flutter run`

کتاب‌ها از `assets/books/` همراه برنامه نصب می‌شوند؛ `assets/books/catalog.json` فرادادهٔ فهرست را مشخص می‌کند. پس از اولین باز شدن، هر کتاب در حافظهٔ دستگاه ذخیره می‌شود و بدون شبکه قابل خواندن است.

سرور Node در `backend/` اختیاری است و همین کتاب‌ها را از طریق HTTP ارائه می‌کند (برای استقرار ازراه‌دور). توضیحات در [backend/README.md](backend/README.md).

## ویژگی‌ها

- کتاب‌خانه با جلدهای تزئینی، برگزیده‌ها و ادامهٔ مطالعه
- علاقه‌مندی، نشانک، برجسته‌سازی و جست‌وجو در کتاب
- تنظیمات خواننده (قلم، فاصله، تراز، پوستهٔ صفحه)
- پوستهٔ روشن / تیره / سیستم برای خود برنامه
- پشتیبانی آفلاین از فهرست و فایل EPUB
