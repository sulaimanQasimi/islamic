# کتاب‌خانهٔ کتاب‌های دری

برنامهٔ آزمایشی Flutter برای مطالعهٔ EPUB، با رابط دری و فهرست کتابِ مدیریت‌شده در backend. کاربر می‌تواند کتاب‌ها را جست‌وجو و مطالعه کند، اما نمی‌تواند کتاب تازه بارگذاری یا فهرست را تغییر دهد.

## راه‌اندازی

1. سرور را اجرا کنید: `node backend/server.mjs`
2. برنامه را در وب یا دسکتاپ اجرا کنید: `flutter run`
3. برای Android emulator از این نشانی استفاده کنید: `flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080/api`

روش افزودن کتاب از backend در [backend/README.md](backend/README.md) آمده است.
